ARROW ESCAPE v4 — MOBILE FIRST, GLOBAL WEAVE + CIRCULAR ORBITS

Upload arrow-escape-v4-mobile-first.zip into the ROOT of your Codespaces repository.
Then paste into Terminal:

unzip -o arrow-escape-v4-mobile-first.zip
cp -a arrow-escape/. ./
rm -rf arrow-escape
rm -f arrow-escape-v4-mobile-first.zip
if [ -d .github/workflows/.github ]; then git rm -r .github/workflows/.github; fi
npm install --no-audit --no-fund
npm test
npm run build:web

ONLY IF ALL SUCCEED:

git add -A
git commit -m "Arrow Escape v4 - mobile-first orbit puzzles"
git push origin main

Go to https://github.com/Subhamalwar/arrow-bottles/actions and download the built Android artifact.

Be aware: reinstalling an APK with a different debug signature may require uninstalling the previous version (local progress could be erased).
